# Changelog

## 0.2.0

- AutoPlay now follows the active OpenChamber Voice provider and settings at playback time.
- Removed extension-owned voice/model/speed playback defaults.
- Added browser PCM decoding support to the OpenChamber host path.
- BKG TTS proxy returns raw signed 16-bit PCM to the browser.
- Added valid extension SVG assets.
- Added Git-based install/update workflow documentation.
